# Kids Mode

A mode built to let a young player sit at the screen alone.

## Where to find it

☰ menu → **Settings** → **Kids Mode** card → **Enable**.

## What it changes

- **Lighter board** — the "Discovery" layout, 7 marbles per side instead of 14. Less material to track, shorter games.
- **Move assist** — before any selection, marbles that have at least one legal move are highlighted. The child no longer has to guess which one can move. The calculation runs through the real engine.
- **Bright marble colors.**

## What it hides

Chat, the AI Lab, settings, and external links.

## Protected exit

Leaving requires solving a two-term addition problem drawn at random. As long as the answer is wrong, the mode stays active.

## Persistence

The state survives a page reload: the mode restores itself on startup, and the addition problem still has to be answered to leave it. A simple refresh doesn't reopen anything.
